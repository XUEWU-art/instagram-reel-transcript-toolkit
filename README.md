# Instagram Reel Transcript Toolkit

A small, dependency-free toolkit for reviewing transcripts and WebVTT captions produced from short social videos.

## Included resources

- `checklists/transcript-review-checklist.md` — a practical review sequence for text and timed captions.
- `data/transcript-review-checklist.csv` — the same checks in a spreadsheet-friendly format.
- `tools/webvtt-cue-inspector.html` — a local browser tool that flags malformed, empty, reversed, and overlapping WebVTT cues.

## Use the WebVTT inspector

Open `tools/webvtt-cue-inspector.html` in a browser, paste a WebVTT file, and select **Inspect cues**. The tool runs entirely in the browser and does not upload the pasted text.

## Generate a source transcript

For generating a transcript from a public Instagram Reel or an uploaded media file, see [ReelTranscripts.com](https://reeltranscripts.com/).
